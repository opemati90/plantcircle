# Edge Functions

| Function             | Schedule                                                   | Does                                                                                                                                                                                                                                             |
| -------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `cron-reminders`     | manual only (the 15-min job runs in the database, pg_cron) | `select notifications_enqueue_due()`: expires waitlist offers, settles orders past their cutoff, day-before and 2-hour reminders, address unlocks, order closing notices                                                                         |
| `web-rsvp`           | on request (POST)                                          | the shared-link RSVP page: finds or makes the guest's auth user, profile, joins with the app's capacity rules, emails a magic link; cancels by token                                                                                             |
| `push-dispatch`      | every 1 min                                                | claims due `push_queue` rows under a lease (`push_queue_claim`), sends through Expo push, marks sent only on accepted tickets, retries up to five attempts, drops dead tokens                                                                    |
| `cook-upload`        | on request (POST, member's token)                          | Cooked it photos: strips every JPEG metadata segment (EXIF/GPS, XMP, IPTC, comments), checks sizes, decodes it, reserves the upload (30 a day), stores the photo and thumbnail in the private `cook-photos` bucket, records the upload; 30 a day |
| `cook-photo-urls`    | on request (POST, member's token)                          | signs Cooked it photos for 10 minutes, only those the member may see (`cook_photos_readable`, asked as the member); members cannot read the bucket themselves                                                                                    |
| `cook-photo-cleanup` | every 10 min                                               | claims queued `cook_photo_deletions` under a lease and removes the photo and thumbnail through the Storage API, then drops the rows                                                                                                              |

All run with the service role. `push-dispatch`, `cook-photo-cleanup` and `cron-reminders` accept only a POST carrying the service-role key (`_shared/workerAuth.ts`); pg_cron calls `push-dispatch` every minute with the key from Vault (migration 20261112003000). Quiet hours, the member's choices and the lock-screen setting are applied when the row is queued (`notify()` in migration 20261112001600), so the dispatcher only sends what is due. Email rows (`email = true`) wait for `email-send`.

Push text is English in v1 (the Inbox row is localised in the app); per-language push copy needs a language on the profile, which is an open item.
